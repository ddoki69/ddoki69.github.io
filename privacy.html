개인정보처리방침

ECO-AI 개인 비서(이하 "이 앱")는 연구자 개인이 본인의 PC에서 사용하는 개인용 도구입니다. 이 방침은 이 앱이 Google 계정 데이터를 어떻게 다루는지 설명합니다.

1. 수집·사용하는 정보

이 앱은 사용자가 OAuth 동의로 허용한 범위 안에서 사용자 본인의 다음 데이터에 접근합니다.

  • Google 캘린더: 일정 조회 및 사용자가 선택한 일정/마감 추가·삭제.
  • Gmail(읽기 전용): 최근 메일의 제목·보낸이·미리보기를 읽어 요약·일정 후보 추출에만 사용. 메일 본문을 외부로 전송하지 않으며, 메일을 보내거나 수정·삭제하지 않습니다.
  • Google Tasks: 할 일(마감) 조회 및 추가·삭제.

2. 데이터의 보관과 처리

  • 데이터 처리는 사용자의 PC와 사용자가 속한 기관의 내부망 서버에서 이루어집니다.
  • 이 앱은 수집한 데이터를 제3자에게 제공·판매·공유하지 않으며, 광고 목적으로 사용하지 않습니다.
  • Google Workspace API로 얻은 데이터는 위에 적힌 기능(일정 정리·브리핑) 외의 목적으로 사용하지 않습니다.

3. 데이터 공유

이 앱은 사용자 본인 계정 외부로 개인 데이터를 전송하지 않습니다. 유일한 '쓰기'는 사용자가 직접 선택한 일정·할 일을 사용자 본인의 Google 캘린더·Tasks에 추가하는 것뿐입니다.

4. 접근 철회

사용자는 언제든지 Google 계정 → 보안 → 타사 앱 액세스에서 이 앱의 접근 권한을 철회할 수 있습니다.

5. Google API 데이터 사용 제한 준수

이 앱의 Google API 정보 사용·전송은 Google API Services User Data Policy(제한된 사용 요건 포함)를 준수합니다.
